# Omni-OS Keybindings Reference

This document outlines the default keybindings for Omni-OS, utilizing the Hyprland compositor. The main modifier key (`Super`) is typically the Windows or Command key.

## Window Management
| Key Combo | Action | Description |
|---|---|---|
| `Super + Q` | Close Window | Closes the active window |
| `Super + F` | Toggle Fullscreen | Maximizes the active window |
| `Super + V` | Toggle Floating | Toggles the active window between tiled and floating modes |
| `Super + Left` | Move Focus Left | Shifts focus to the left window |
| `Super + Right` | Move Focus Right | Shifts focus to the right window |
| `Super + Up` | Move Focus Up | Shifts focus to the upper window |
| `Super + Down` | Move Focus Down | Shifts focus to the lower window |
| `Super + Shift + Left` | Move Window Left | Moves the active window left |
| `Super + Shift + Right` | Move Window Right | Moves the active window right |

## Workspace Navigation
| Key Combo | Action | Description |
|---|---|---|
| `Super + 1-9` | Switch Workspace | Switches to workspace 1 through 9 |
| `Super + Shift + 1-9` | Move to Workspace | Moves the active window to workspace 1 through 9 |
| `Super + Mouse Scroll` | Scroll Workspaces | Quickly cycle through active workspaces |

## Omni Intelligence Suite
| Key Combo | Action | Description |
|---|---|---|
| `Super + Space` | AI Assistant | Summons the Omni-OS conversational agent overlay |
| `Super + Shift + A` | Omni-Automator | Trigger zero-code OS command agent |
| `Super + S` | Omni-Recall Search | Search your encrypted OCR timeline history |
| `Super + Shift + D` | Deep Work Mode | Toggles distraction blocking and Observer focus mode |

## Applications
| Key Combo | Action | Description |
|---|---|---|
| `Super + Return` | Terminal | Launches the default terminal emulator |
| `Super + D` | App Launcher | Opens the application menu / rofi / wofi |
| `Super + E` | File Manager | Opens the default file manager |
| `Super + B` | Web Browser | Launches the default web browser |

## Screenshots & Media
| Key Combo | Action | Description |
|---|---|---|
| `PrintScreen` | Full Screenshot | Captures the entire screen |
| `Super + Shift + S` | Region Screenshot | Select a region to capture to clipboard |
| `Media Play/Pause` | Play/Pause | Controls media playback |
| `Volume Up/Down` | Adjust Volume | Increases or decreases system volume |

## System
| Key Combo | Action | Description |
|---|---|---|
| `Super + Shift + E` | Exit Menu | Opens the power/logout menu |
| `Super + L` | Lock Screen | Locks the current session |
